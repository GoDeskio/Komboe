docker pull ghcr.io/godeskio/komboe-server:TBD

Accounts: local Komboe accounts by default; optional enterprise SSO via OIDC or SAML (e.g. Keycloak, Okta).

Your self-hosted server never contacts Komboe, and outside services stay off unless you turn them on or run a check. Set your server URL in the apps when you first sign in. See the switches in docs/RUNNING.md.
