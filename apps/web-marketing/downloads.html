Self-host server

Run your own Komboe sync server from the published container image.

Local accounts are the default. Optional enterprise single sign-on can be added by the operator.

Your self-hosted server never contacts Komboe, and outside services stay off unless you turn them on or run a check. Set your server URL in the apps when you first sign in. The switch list is in docs/RUNNING.md in the Komboe source.
