Security and zero-knowledge

Vault contents are encrypted on your device before upload. Account metadata is described in the Privacy Policy.

How Komboe protects your vault

🧮

On-device encryption

Every vault item is encrypted on your device before it is stored or synced.

🗝️

Master password stays local

Your master password never leaves your device. Keys are uploaded only in encrypted form.

☁️

Encrypted before upload

A copy of the server alone does not reveal vault contents.

🚫

No backdoor

No escrow key, no hidden recovery path, no exceptions.

🔁

No admin password reset

Neither Komboe nor an organization admin can reset your master password.

🔍

Open source

The Komboe source is public so anyone can read how the vault is protected.

One account, every device

You sign in with your email and master password, and optionally a passkey and two-step login. The password is used on the device to derive the keys that decrypt the vault.

Self-hosting

A self-hosted Komboe server does not contact Komboe. Outside services stay off unless you turn them on. Desktop and CLI update checks stay off until you point them at a feed you host. A breach check runs only when you ask for it. Password checks send only a k-anonymity hash prefix, never the password. The data breach report sends your email address to your Komboe server, which forwards it only if the operator has configured a breach-check key. The web vault uses the server it was loaded from. Until you save a server URL, some apps still have a cloud default compiled in. Set your server URL when you first sign in. The switch list is in docs/RUNNING.md in the Komboe source.

Accounts and sign-in

What is a Komboe account?

One Komboe account syncs the web vault, browser extensions, phone, desktop, command line and the assistant. You sign in with your email and master password, and you can add a passkey and two-step login.

Does Komboe ever see my master password?

No. The home page and the web vault hash the master password on the device. Only that hash is sent, and the vault is encrypted before it syncs.

Can an admin reset my master password?

No. There is no backdoor and no admin password reset. Keep your recovery kit safe.

Does this website ask for my password?

Yes. The home page sign-in form uses the same flow as the web vault, including a two-step code when the account has one. The password stays in the browser and is not stored on this site.

What about self-hosting?

Self-hosted servers use local Komboe accounts by default. Organizations can optionally add enterprise single sign-on. Vault decryption still needs each person's master password. Komboe assistant

Asks your Komboe agent after you sign in. It can explain a feature, suggest next steps, or generate a password. It never reads vault items.
