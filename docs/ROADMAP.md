# Komboe Roadmap

- **M0 Scaffolding** — repo, README/credits, architecture, threat model, import + rebrand scripts, RailYard lint/license checks.
- **M1 Import & rebrand** — pinned subtree import of Bitwarden clients (minus `bitwarden_license/`) and Vaultwarden; strip upstream branding; builds green.
- **M2 Core vault** — web vault + server, E2E verified, self-host docker compose.
- **M3 Orgs** — family/company orgs, admin seats, personal vault isolation, admin-approved split-off.
- **M4 All clients** — desktop, browser extensions, CLI, mobile.
- **M5 Aliases** — SimpleLogin integration.
- **M6 Hosted dashboard** — Proton Pass-style dashboard, subscription billing (minimal metadata). Requires owner approval for billing.
- **M7 Hardening** — audit, reproducible builds, legal review (Marcus) before commercial launch; store submissions only with owner approval.
