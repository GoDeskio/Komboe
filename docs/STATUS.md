## Email notifications (2026-10-30)

`tests/features/emails.py` against a local test server (SMTP -> Mailpit, no production). Scheduled jobs are triggered by running the server with `EMERGENCY_NOTIFICATION_REMINDER_SCHEDULE`, `EMERGENCY_REQUEST_TIMEOUT_SCHEDULE` and `INCOMPLETE_2FA_SCHEDULE` set to `*/5 * * * * *`, `JOB_POLL_INTERVAL_MS=1000`, and backdating `recovery_initiated_at` / `twofactor_incomplete.login_time` in the test DB. Result: 35/35 pass. Not covered: SSO (not configured).
