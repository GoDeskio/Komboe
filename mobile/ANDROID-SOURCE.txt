Rebuild
  git clone --depth 1 --branch v2026.10.1-bwpm https://github.com/bitwarden/android.git
  # then, in a Komboe checkout at the matching revision:
  SRC=/path/to/android mobile/android-build.sh

Vault crypto is Komboe's own GPL-3.0 code in mobile/vault-crypto, built on Bouncy Castle (MIT). No Bitwarden SDK is linked.

There is no admin password reset and no key escrow in this app.
